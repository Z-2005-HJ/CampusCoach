# 项目文档

本目录保存可追溯的开发文档。聊天记录不能替代这里的规格、任务、决策和验证记录。

## 当前内容

- `harness/`：Development Harness 建设和验收记录。

## 后续目录

以下目录将在对应 Harness 步骤建立：

- `specs/`：可审核的功能规格。
- `tasks/`：任务范围、状态和验证结果。
- `adr/`：重要技术和架构决策。
- `worklog/`：日常执行记录和恢复入口。

在模板和规则建立前，不要创建没有验收标准的功能规格或伪任务。

## 记录原则

- 记录事实，不把计划内容写成已经实现。
- 命令结果必须区分未运行、失败和通过。
- 未知信息和未解决风险必须明确保留。
- 文档只引用合成数据，不包含真实健康资料、身份信息或密钥。
